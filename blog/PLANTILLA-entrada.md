## Así se ve un subtítulo

Para crear un subtítulo, escribe dos signos de número (##) y un espacio antes del texto.

Puedes poner palabras en **negrita** encerrándolas entre dos asteriscos.

### Subtítulo más pequeño

Usa tres signos de número (###) para un subtítulo de menor jerarquía.

Para hacer una lista de puntos:

- Primer punto
- Segundo punto
- Tercer punto

Para una lista numerada:

1. Primer paso
2. Segundo paso
3. Tercer paso

> Esto es una cita destacada. Sirve para resaltar una frase importante o una reflexión.
